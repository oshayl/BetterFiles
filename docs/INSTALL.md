# Installation and First Run

## Requirements

- Photoshop **25.0 or later** (2024+). Enforced by the manifest.
- macOS or Windows. The plugin cannot run anywhere else, because Photoshop does not.
- [Adobe UXP Developer Tool](https://developer.adobe.com/photoshop/uxp/devtool/)
  for development loading.

## Development loading (recommended for the first run)

```bash
npm install
npm run build
```

1. Open **Adobe UXP Developer Tool**.
2. **Add Plugin** → select `dist/manifest.json`.
3. Click **Load**.
4. In Photoshop: **Plugins → Asset Browser**.

`npm run watch` rebuilds on change; press **Reload** in the Developer Tool to
pick up the new bundle.

## Packaged install

```bash
npm run package
```

Produces `asset-browser-<version>.ccx`. Double-click it to install through
Creative Cloud.

Adobe requires plugins distributed through the Marketplace to be signed. A
locally produced `.ccx` is fine for your own machines and for sharing within a
team that is willing to allow unsigned plugins; Marketplace submission needs
Adobe's signing flow.

## Permissions

The manifest requests two permissions, both in `manifest.json` where you can
inspect them:

**`localFileSystem: "fullAccess"`** — required because libraries must survive a
restart, live on external drives and network shares, and be indexed recursively.
A more restrictive mode would force re-picking every folder on every launch.

**`launchProcess`** — used only by *Reveal in File Manager*, to open Finder or
Explorer at a file. It is scoped to the `file` scheme and the supported asset
extensions.

No network permission is requested. The plugin cannot send your assets anywhere.

## Importing many libraries at once

A pack collection is usually one parent folder holding many library folders,
often as `<Pack Name>/SVG`. Adding those one at a time means one trip through
the folder picker each.

**SCAN** (next to *ADD FOLDER*) takes the parent folder instead. It finds every
folder beneath it that directly contains supported assets, and offers them as a
checklist with a name and category already suggested from the folder names —
`Cyber Label Pack/SVG` becomes the library *Cyber Label Pack (SVG)* filed under
*Cyber Label*. Suggestions are editable before you confirm; folders already
imported are listed but greyed, so a correct scan never looks like a short one.

Scanning looks two levels down, which covers `<Pack>/<Format>`.

## Backing up your libraries

Libraries and the asset index live in the plugin's private storage:

```
.../UXP/PluginsStorage/PHSP/<ps-version>/External/<plugin-id>/PluginData/database/
```

That is keyed by plugin id, **not** by plugin version, so **updating the plugin
keeps your libraries**. What does not survive is a Photoshop *major* upgrade
(the path contains the Photoshop version), a reinstall through Creative Cloud,
or a move to another machine.

**Settings → Back Up Libraries** writes `asset-browser-libraries.json` to a
folder you choose: the paths, names and categories, a few kilobytes. **Restore
Libraries** reads it back, re-acquires each folder by path and re-indexes.

Two things are deliberately left out of the backup:

- **Persistent tokens**, which are scoped to one machine and one install. A
  copied token resolves to nothing, so restore mints fresh ones.
- **The asset index**, which is large and rebuilt exactly by re-indexing.

Restore needs the drives mounted; anything it cannot find is reported by count
rather than skipped silently.

## First run

1. Click **ADD FOLDER** and pick a folder of assets.
2. Indexing starts immediately; the header shows progress and the grid fills in
   as files are found.
3. Click an asset to preview it, then **Insert** or double-click to place it.

**Run the self-test before relying on it.** Open **Settings → Self-Test** with a
document open and click **Run Self-Test**. See [SELF-TEST.md](SELF-TEST.md) for
what each check means. This is the roadmap's Phase 0 spike, and it has not been
run on real hardware yet.

## Supported formats

| Category | Extensions | Preview |
|---|---|---|
| Raster | png, jpg, jpeg, webp, gif, tif, tiff, bmp | Direct from file |
| Vector | svg | Direct from file |
| Vector | ai, eps | Generated by Photoshop |
| Document | pdf | Generated by Photoshop, first page |
| Photoshop | psd, psb | Generated by Photoshop |

Anything else is ignored during indexing.

## Keyboard shortcuts

| Shortcut | Action |
|---|---|
| Cmd/Ctrl + K | Focus search |
| Cmd/Ctrl + F | Focus search (fallback) |
| Cmd/Ctrl + R | Refresh the active library |
| Enter | Insert the selected asset |
| Cmd/Ctrl + Enter | Open the selected asset as a document |
| Arrow keys | Move selection |
| Home / End | Jump to first / last asset |
| F | Favourite the selected asset |
| Escape | Clear search, then clear selection |

Photoshop owns some shortcuts globally; the self-test does not check for
conflicts, so verify these behave as expected on your setup.

## Troubleshooting

**The panel is blank.** The bundle failed to load. Check the Developer Tool
console. `bootstrap.tsx` falls back from React 18's `createRoot` to the legacy
`ReactDOM.render`, and logs which path it used.

**A library shows "Unavailable".** The drive is disconnected or the folder
moved. Click **Reconnect** and re-pick it.

**Libraries disappear after restarting Photoshop.** The persistent token could
not be minted. The self-test's *Persistent folder tokens* check reports this
directly.

**Thumbnails are missing for PSD/PDF/AI.** These require Photoshop to generate a
preview, one at a time. If they stay blank, run the self-test's *Imaging API*
check. Files above the size limit in Settings are skipped by design.

**An Illustrator file shows "Preview unavailable".** The `.ai` was probably saved
without PDF compatibility, which is the documented limitation in §19.5. Re-save
it from Illustrator with *Create PDF Compatible File* enabled.

**Insert does nothing.** Check a document is open. Errors appear in a bar at the
bottom of the panel.

**Reporting a problem.** **Settings → Export Diagnostics** writes a log
containing paths, counts and errors — no asset contents — and reports where it
was saved.
